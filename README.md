# Mô phỏng mạng di động 5G, 4G, 3G

## Nội dung

- 37 thẻ mô phỏng về kiến trúc, truy nhập vô tuyến, mạng lõi, truyền dẫn, bảo mật, tối ưu và các chủ đề liên quan.
- 233 KPI, 12 luồng E2E, 4 chế độ mạng và 3 bộ tham số vendor.
- Các sơ đồ tương tác, bộ điều khiển luồng, tùy chọn cell, tìm kiếm, theme sáng/tối và nội dung giải thích.

## Mở trang

Mở `index.html` bằng trình duyệt hoặc phục vụ thư mục này bằng một static web server.

## Cấu trúc

- `index.html`: bố cục trang và nội dung HTML.
- `assets/css/`: kiểu giao diện, theme sáng/tối và bố cục responsive.
- `assets/js/`: mô phỏng, sơ đồ, dữ liệu nội dung và tương tác của các thẻ.
